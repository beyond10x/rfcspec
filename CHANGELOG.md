# Changelog

## Unreleased

- The design: `docs/design/rfcspec.md`.
- RFCspec's own ESS domain in `ess/`.
- The documentation site under `website/`, generated pages from `crates/rfcspec-docs`.
- The protocol catalogue at `/docs/catalog/`: an index of every profile under `profiles/` and one
  page per profile (RFCs, communication semantics, requirement matrix, ESS gaps, conformance,
  downloads of `generated/`), all generated by `rfcspec-docs` and drift-checked.
- An overlay's `kind` (K1 to K8) and a profile's per-layer communication semantics, checked by
  `rfcspec check`; `rfcspec check --all <dir>`.
- `rfcspec verify --report` records a run as an `rfcspec-run/1` report; `rfcspec check` fails on a
  report whose overlay digest is stale.
